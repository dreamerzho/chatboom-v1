# 字段释义与赋值建议

> 本文档基于 docs/表名与字段.md，梳理所有表及字段的含义、数据来源、计算逻辑与赋值建议，便于后续数据归档、ETL、API 开发等场景参考。

---

## 说明：

- **统计分析/聚合**：指通过数据库聚合函数、业务逻辑脚本等，对原始数据进行统计、加权、分组、求和、均值、最大/最小值等操作，得出汇总性指标。需明确具体聚合方式。
- **归一化**：指将原始数据标准化为统一格式或 ID，常见方式包括：名称转 ID、去除空格/特殊字符、统一大小写、映射表转换等。需明确具体归一化规则。
